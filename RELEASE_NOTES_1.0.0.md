# HTML External Opener 1.0.0

Initial public release.

- Open local HTML links from rendered Markdown in the operating system's default HTML application.
- Optionally launch a user-configured browser executable.
- Add a Command Palette command for Markdown links under the editor cursor.
- Restrict resolved targets to regular files inside the current Vault.
- Avoid shell command construction when launching a configured browser.
- Preserve settings from the earlier prototype build.
- Include automated unit tests and a dependency-free build script.
