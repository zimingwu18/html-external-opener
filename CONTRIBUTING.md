# Contributing

1. Open an issue to describe a bug or proposed change before starting substantial work.
2. Keep changes focused and avoid adding runtime dependencies without a clear need.
3. Run `npm run check` before submitting a pull request.
4. Do not include generated `main.js` or `release-assets/` in commits; these are created for releases.
5. Include reproduction steps and the Obsidian/OS versions for bug reports.
